# YaCut — Сервис укорачивания ссылок и асинхронной загрузки файлов

**YaCut** — это веб-сервис, который решает проблему длинных интернет-адресов. Он позволяет превратить громоздкую ссылку в короткую и эстетичную. В сервис интегрирована возможность пакетной асинхронной загрузки файлов в облачное хранилище с автоматической генерацией коротких ссылок на них.

---

## Стек технологий

* **Backend:** Python 3.9+, Flask (микрофреймворк)
* **Асинхронность:** Asyncio, Aiohttp (для эффективной параллельной работы с API Яндекс Диска)
* **Работа с БД:** Flask-SQLAlchemy (ORM), Flask-Migrate (управление миграциями)
* **Формы и валидация:** Flask-WTF, WTForms
* **Frontend:** HTML5, CSS3, Bootstrap 5, Jinja2 (шаблонизатор)
* **Окружение:** Разделение конфигурации через Python-dotenv

## Как развернуть и запустить проект

### 1. Клонирование репозитория
Клонируйте репозиторий и перейдите в корневую директорию проекта:
```bash
git clone https://github.com
cd yacut
```

### 2. Виртуальное окружение
Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
```
* **Для Linux/macOS:**
  ```bash
  source venv/bin/activate
  ```
* **Для Windows:**
  ```bash
  venv\Scripts\activate
  ```

### 3. Установка зависимостей
Обновите менеджер пакетов `pip` и установите все необходимые библиотеки:
```bash
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения (`.env`)
Создать в директории проекта файл .env с четыремя переменными окружения: 
```env
# Имя Flask-приложения для запуска
FLASK_APP=yacut

# Режим работы (development — для разработки, production — для продакшена)
FLASK_ENV=development

# Секретный ключ для защиты форм и сессий (замените на свой случайный набор символов)
SECRET_KEY=your_secret_key

# Ссылка для подключения к базе данных (по умолчанию SQLite)
DB=sqlite:///db.sqlite3
```

### 5. База данных и миграции
Создайте локальную базу данных и примените существующие миграции:
```bash
flask db upgrade
```

### 6. Запуск сервера
Запустите встроенный веб-сервер Flask:
```bash
flask run
```
После запуска проект будет доступен в вашем браузере по адресу: `http://127.0.0:5000`.
